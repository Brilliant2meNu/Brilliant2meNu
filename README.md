## What I've built

### Beauty by Jingmei-ko: a connected salon system
A real, working tech setup for a skincare studio in Torrance, CA. One owner runs it from her phone.

- **Website**: [beautybyjingmeiko.com](https://www.beautybyjingmeiko.com). An editorial site with live appointment availability pulled from Square.
- **Studio Admin**: the owner updates hours, prices and policies from any phone, previews the change on the real site, and publishes it. No code, with one-tap undo.
- **Lily**: an AI assistant that answers client questions and books real appointments into Square. [Try Lily →](https://jmk-salon-chatbot.vercel.app)
- **Front-door kiosk**: a Raspberry Pi display. Passersby scan a QR code to browse services and chat with Lily. A repurposed PS2 EyeToy camera wakes it when someone walks up.

### Nia: a multi-business AI consultant
A voice-enabled chat assistant built to be dropped into any business. Each business is a swappable knowledge module.
